# Backend replacement matrix

Legend: **Data** = Data API with RLS; **RPC** = PostgreSQL function; **Edge** = Edge Function; **Trig** = trigger; **Queue** = Cron/queue worker; **Store** = Supabase Storage. Difficulty is relative to this repository.

The matrix groups endpoints that share the same aggregate, authorization rule, transaction boundary, and replacement. All 19 controllers and their endpoint families are represented.

## Removal gate

No row in this matrix authorizes deletion of its NestJS implementation. Removal is an S8 action only after its replacement has passed the listed tests, reconciliation is clean, rollback has been rehearsed, and the product owner approves cutover.
