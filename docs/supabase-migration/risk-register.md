## Phase S0 blockers

S0 does not close implementation risks. It establishes decisions and gates. Production migration remains blocked by authoritative migration conversion, substantive drift classification, Auth hash rehearsal, complete RLS implementation, object reconciliation, Edge workload benchmarks, staging-scale import/recovery, and approved cutover operations.
